# Surge 每日内容 Panels

本模块提供三个相互独立的 Panel：

1. **诗词与一言**：每天 08:00 通知推送。
2. **西语·中英每日一句**：每天 12:00 和 17:00 通知推送。
3. **有道每日一句**：显示英文、中文和作者；点击 Panel 打开当天高清配图。

现有推送内容和时间不因新增有道 Panel 而改变。

## 安装

在 Surge 中打开「首页 → 模块 → 安装新模块」，粘贴：

```text
https://raw.githubusercontent.com/Jimmyzsan/Surge2025/main/daily-poem.sgmodule
```

Panel 每小时刷新，也可以点击手动刷新。

> Surge Panel 官方格式不支持直接嵌入远程图片，因此有道配图通过点击 Panel 打开。
